# Histórico de alterações

## 1.0.0 — 2026-09-25

- Reimplementação com React, Phaser Arcade Physics e Vite.
- Adicionados modos Clássico, Sobrevivência e Duelo local.
- Adicionadas regras documentadas de colisão, pontuação, vidas e power-ups.
- Controles por teclado, mouse/toque e Gamepad API.
- Adicionados testes Vitest para regras determinísticas, comandos de build/teste e documentação de QA.
- Organizada a documentação em `docs/`.

## Origem

Esta implementação é uma reestruturação do projeto público [davidcreator/Breakout-Classico](https://github.com/davidcreator/Breakout-Classico). O histórico e o código do repositório de origem devem ser consultados no GitHub; esta pasta não altera automaticamente aquele remoto.
